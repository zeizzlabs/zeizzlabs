# ZeizzLabs — asset brief

Everything the site can display, the exact path it reads, and a prompt to
generate it. **Filenames are the contract**: drop a file at the listed path and
it appears. No code change, no rebuild step beyond the normal one.

Placeholders exist for every image below (generated by
`python3 scripts/generate-art.py`), so nothing is broken while you work through
this. Replace them in any order.

---

## House style — put this in every image prompt

> Deep navy-black background (#04060C). Electric blue (#1E7BFF) and champagne
> gold (#DCB877) as the only accent colours, with brushed steel (#A4B3C9) for
> structure. Circuit-board motifs: orthogonal traces with rounded corners and
> small ring-shaped terminal pads. Premium, restrained, technical. Cinematic
> lighting, subtle film grain, no text, no logos, no watermarks, no people
> unless stated.

Avoid: purple, teal, neon pink, lens flares, stock-photo gloss, generic "AI
brain" imagery, floating holograms, cliché matrix code rain.

## 4. Video — optional

Any image on the site can have a short looping video play on top of it. This is
optional. Skip the whole section if you only want still images.

### How to add one

**Step 1.** Pick an image you want to make move. Say this one:

```
public/media/work-voice-reception.jpg
```

**Step 2.** Make a video for it, using the specs below.

**Step 3.** Name the video **exactly the same as the image**, but ending in
`.mp4` instead of `.jpg`:

```
work-voice-reception.jpg   <- the image that is already there
work-voice-reception.mp4   <- your new video, same name
```

**Step 4.** Put the `.mp4` in the same folder, `public/media`.

**Step 5.** Restart the site:

```bash
npm run dev
```

That is all. The video is found automatically because of its name. You do not
edit any code.

### What happens on the page

- The image shows first, immediately. The video fades in once it has loaded.
- If the video is slow or fails, the image just stays. Nothing breaks.
- The video is silent and repeats forever.
- It stops playing when you scroll past it, and does not play at all for
  visitors who have asked their device to reduce animation.

### Specs to give whoever makes the video

| | |
| --- | --- |
| Format | MP4 |
| Size | 2400 x 1000 pixels |
| Length | 4 to 8 seconds |
| Sound | None. Remove the audio track entirely |
| File size | Under 3 MB |
| Looping | The last frame should match the first, so the repeat is invisible |

That last one matters most. A video that ends somewhere different from where it
started will visibly jump every few seconds.

### What to make a video of

For the four project images, a **screen recording of the actual product** is far
better than anything generated. Crop it to the interesting part, and do not
include the mouse cursor or browser chrome.

If you want a generated one instead, use this prompt:

> Slow drift across a dark circuit-board surface, pulses of blue and gold light
> travelling along the traces, shallow depth of field, seamless loop, no cuts,
> no text.

### To remove a video later

Delete the `.mp4` and restart. The image takes over again on its own.

**`zeizzlabs-logo.png` is the old neon purple/orange board.** It no longer
matches the navy/blue/gold brand and is no longer used anywhere on the site.
Either regenerate it in the current palette or delete it.

**A simplified mark is the one real gap.** The detailed monogram turns to mush
below about 40px — in the navbar, and worst in a browser tab. Prompt:

> A minimal single-letter Z monogram derived from a detailed circuit-board Z.
> Keep only the bold outer Z silhouette with one angled diagonal cut and at most
> three thick circuit traces. Electric blue with a single champagne gold trace.
> Flat, no bevel, no 3D, transparent background, readable at 32 pixels. Vector,
> centred, square canvas.

Save it as `zeizzlabs-mark-simple.png`, then in
`components/brand/Logo.tsx` point `MARK_SRC` at it for UI sizes.

## After adding files

```bash
npm run build
```

Regenerating the placeholders at any time:

```bash
python3 scripts/generate-art.py
python3 scripts/generate-og.py
```

Both overwrite in place, so run them only if you want the generated art back.
