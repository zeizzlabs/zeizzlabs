# ZeizzLabs — asset brief

Everything the site can display, the exact path it reads, and a prompt to
generate it. **Filenames are the contract**: drop a file at the listed path and
it appears. No code change, no rebuild step beyond the normal one.

Placeholders exist for every image below (generated by
`python3 scripts/generate-art.py`), so nothing is broken while you work through
this. Replace them in any order.

---

## House style — put this in every image prompt

> Deep navy-black background (#04060C). Electric blue (#1E7BFF) and champagne
> gold (#DCB877) as the only accent colours, with brushed steel (#A4B3C9) for
> structure. Circuit-board motifs: orthogonal traces with rounded corners and
> small ring-shaped terminal pads. Premium, restrained, technical. Cinematic
> lighting, subtle film grain, no text, no logos, no watermarks, no people
> unless stated.

Avoid: purple, teal, neon pink, lens flares, stock-photo gloss, generic "AI
brain" imagery, floating holograms, cliché matrix code rain.

## 4. Video — optional, high impact

`Frame` accepts a clip. The still becomes the poster, so the frame is never
empty while it buffers, and if autoplay is blocked the image simply stays.

Add a clip next to any image with the same name, then pass it:

```tsx
<Frame src="/media/work-vox.jpg" video="/media/work-vox.mp4" />
```

Specs: **MP4 (H.264) and WebM**, 2400 × 1000, **4–8 seconds, seamless loop**,
**no audio**, under **3 MB**. Muted, looping and inline are already set; playback
is paused whenever the frame is off screen and disabled entirely for visitors
who ask for reduced motion.

Prompts:

- **Hero / studio loop** — Slow drift across a dark circuit-board surface,
  pulses of blue and gold light travelling along traces, shallow depth of field,
  seamless loop, no cuts.
- **Per project** — A screen recording of the real product beats anything
  generated. Crop to the interesting region, no cursor, no chrome.

**`zeizzlabs-logo.png` is the old neon purple/orange board.** It no longer
matches the navy/blue/gold brand and is no longer used anywhere on the site.
Either regenerate it in the current palette or delete it.

**A simplified mark is the one real gap.** The detailed monogram turns to mush
below about 40px — in the navbar, and worst in a browser tab. Prompt:

> A minimal single-letter Z monogram derived from a detailed circuit-board Z.
> Keep only the bold outer Z silhouette with one angled diagonal cut and at most
> three thick circuit traces. Electric blue with a single champagne gold trace.
> Flat, no bevel, no 3D, transparent background, readable at 32 pixels. Vector,
> centred, square canvas.

Save it as `zeizzlabs-mark-simple.png`, then in
`components/brand/Logo.tsx` point `MARK_SRC` at it for UI sizes.

## After adding files

```bash
npm run build
```

Regenerating the placeholders at any time:

```bash
python3 scripts/generate-art.py
python3 scripts/generate-og.py
```

Both overwrite in place, so run them only if you want the generated art back.
